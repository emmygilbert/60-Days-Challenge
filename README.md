# 60-Days-Challenge

User Input
     ↓
Data Processing
     ↓
AI Model / Decision Making
     ↓
Generated Response
     ↓
Output to User


A chatbot is an AI system that interacts with users through text or voice.
It first receives the user’s input and processes the information.
The AI model analyzes the meaning and intent behind the message.
Based on training data and algorithms, it generates the most suitable response.
Finally, the chatbot displays the response back to the user in real time.

3 Real-World AI Products

1. ChatGPT — Input: text prompt | Processing: LLM (transformer) | Output: generated text
2. Google Translate — Input: text in lang A | Processing: neural MT model | Output: text in lang B
3. Spotify Recommendations — Input: listening history | Processing: collaborative filtering + audio features | Output: ranked song list

4.  Day 6 — Machine Learning Intuition
5.  https://teachablemachine.withgoogle.com/models/XCcnZix0nt/
   

Observations

1. Models perform better with more diverse and consistent training data.

2. Poor lighting and noisy backgrounds reduce prediction accuracy.

3. Machine learning models learn patterns from examples instead of truly understanding objects like humans.
